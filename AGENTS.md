# Cómo trabajar en este repositorio

## Enfoque pedagógico: equilibrio teórico-práctico

La enseñanza debe mantener un **equilibrio cuidadoso** entre teoría y práctica:
- **La teoría es el cimiento**, no el obstáculo: se transmite de forma intuitiva y fácil de asimilar, sin caer en lo académico.
- **Lo práctico viene después**: primero se entienda «por qué» funciona algo, luego se hace. La práctica se apoya en ese conocimiento previo para ser más efectiva.
- **Evita las clases demasiado teóricas**: los alumnos no vienen por teoría pura; vienen porque quieren resolver problemas reales con lo que aprenden.

## Pensamiento de solución sobre Python

**Python es el medio, no el fin.** 
- No se trata de enseñar sintaxis de Python como si fuera un fin en sí mismo.
- El objetivo es **enseñar a pensar cómo solucionar problemas**: entender el problema, descomponerlo, elegir herramientas y aplicarlas.
- Si los alumnos aprenden a razonar lógicamente, podrán transferir ese pensamiento a cualquier lenguaje o tecnología.

## Público: principiantes con poca experiencia

- Usá sintaxis básica de Python y explicaciones sencillas.
- Centrá la clase en **qué se puede hacer**, cuál es el alcance real y cuáles son los beneficios prácticos.
- El código sirve para demostrar un concepto; no es el objetivo principal de aprendizaje.

## Recursos visuales

- Usá diagramas ASCII y Mermaid para explicar conceptos complejos (los diagramas Mermaid finales en formato SVG).
- Apoyá las explicaciones con enlaces a imágenes de Internet y videos de YouTube pertinentes.
